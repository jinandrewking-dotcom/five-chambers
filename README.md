# Five Chambers

A personal one-page site — a hive of five obsessions: Buddhist youth, LGBTQ+ advocacy, tea-zen, automotive data, and solo road trips.

## Edit

- **Identity** (name, email, social links): open `index.html`, edit the `const SITE = { ... }` block near the bottom. One block updates the whole site.
- **Road log / content**: edit the HTML sections directly. (Ask me about a data-driven refactor to make this one-line-per-entry.)

## Deploy

Connected to Netlify: every `git push` to `main` auto-publishes in ~30s.

## Stack

Single self-contained `index.html` — no build step. Fonts via Google Fonts (Fraunces, Instrument Sans, Noto Serif SC).
